Which level? Easy: every square can be found by simple logic, great for beginners. Medium: a few more logic steps, never guessing. Hard: for experienced solvers. Volumes 3 and 6 move from one level to the next.

Questions

Is the large-print sudoku free?

Yes. 8 free puzzles (3 Easy, 3 Medium, 2 Hard), each a one-page PDF with the answer key.

How big are the numbers?

Extra-large and bold (38 point), with thick lines around each 3 x 3 box, one puzzle per page.

Which level should I start with?

Start with Easy: every square can be found with simple logic. Move to Medium when Easy feels quick. Hard is for experienced solvers.

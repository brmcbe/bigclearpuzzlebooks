# Big Clear Puzzle Books website

Static site: https://bigclearpuzzlebooks.com/ (Cloudflare Pages; GitHub Pages turned off)

Free large-print word search printables that link to the Etsy shop (bigclearpuzzlebooks.etsy.com).
Generated by `tools/build_site.py` from `tools/books.json`; venture docs live in the private repo brmcbe/ventures (puzzle-books/).

Add a free printable: PDF in `downloads/`, preview JPG in `img/`, entry in `tools/books.json` (+ SEO line in build_site.py), run `python3 tools/build_site.py`, commit, push.

## Amazon paperback links
When a KDP paperback is Live, add `"asin": "B0XXXXXXXX"` to that book in `tools/books.json` and rerun `python3 tools/build_site.py`. A "Paperback on Amazon" button appears on its free page.
